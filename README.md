# Guji Toolkit (古籍工具集)

**开源古籍数字化全流程工具集**

Guji Toolkit 是一个专为古籍数字化项目设计的开源工具集合。它旨在提供从古籍录入、扫描、识别到校对、版本管理等全生命周期的技术支持，帮助研究人员和开发者更高效地处理古籍资料。

## 🎯 项目目标

本项目的核心目标是构建一个灵活、强大的古籍处理平台。它不仅仅是一个单一的软件，更是一个标准化的接口中心，连接各种底层的处理能力。

主要特点：
*   **模块化设计**: 核心仓库作为一个“壳”（Shell）或集成平台，具体的底层功能（如OCR模型、校对算法）将尽量以独立仓库或包（Package）的形式开发并引入。
*   **多平台支持**:
    *   **Desktop (桌面版)**: 功能最全，性能最强，适合大规模数据处理和深度校对。
    *   **Web (网页版)**: 便于协作和轻量级访问。
    *   **Mobile (移动版)**: 计划开发，提供便捷的查询和简单的辅助功能（因设备限制，功能会做适当精简）。

## 🚀 核心功能

Guji Toolkit 涵盖了古籍数字化工作流中的关键环节：

*   **📷 数字化录入**: 支持古籍扫描件的导入与管理。
*   **🔍 文字识别 (OCR)**: 集成先进的OCR技术，将图像转换为文本。
*   **📝 智能校对**:
    *   提供多层次的校对工具。
    *   支持生僻字查询与辅助输入。
    *   **版本对比**: 能够对比不同版本之间的差异，支持复杂的版本追踪。
*   **👥 协作管理**: 记录校对人员的工作轨迹，支持多人协作、互相审核（Approval）流程。
